Частые вопросы

Страница не открывается. Что проверить?
Обнови страницу, проверь адрес и попробуй открыть её в другом браузере. Если GitHub Pages только что обновился, публикация может ещё выполняться.
Mini App не загружается?
Проверь подключение к интернету и попробуй открыть Mini App по прямой ссылке в браузере. Если появляется код ошибки, сохрани его и текст сообщения для диагностики.
Где скачать Lunary VPN Client?
Клиент Windows находится в ранней разработке. Не запускай старые сборки, если они показывают ошибку. Проверяй только установщик из актуального релиза или проверенной сборки проекта.
Все карточки в Hub уже работают?
Нет. В Hub часть карточек обозначает планы развития. Текущий статус конкретного продукта указан в его карточке; не считай раздел «В планах» готовым сервисом.
Важно о безопасности. Не отправляй никому пароли, приватные ключи, VPN-ссылки подписки или конфигурационные файлы. Для сообщения об ошибке достаточно скриншота без личных данных и текста ошибки.

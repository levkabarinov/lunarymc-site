# LunaryMC website

Отдельный сайт проекта LunaryMC.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

Сайт собирается Vite и публикуется в GitHub Pages через workflow в `.github/workflows/deploy.yml`.

GitHub Pages должен быть включён в настройках репозитория с источником **GitHub Actions**.
